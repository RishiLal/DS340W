# Method specification fixed before fitting

This amendment and the November 7 outer protocol govern the first extension fit. The November 6 proposal remains as a dated research record.

1. All four models use the 153 US factors eligible in the initial 210 Training months, plus the excess market return as a test asset. All 153 passed the five-stocks-per-leg screen and had complete Training histories. The authors' current public factor returns already incorporate their sign convention. Across the 73 negative-direction series, the median correlation with the signed historical series was 0.99968 in Training. Applying the direction again would reverse these assets. The median standard-deviation ratio across all factor matches was 1.00017. The lowest signed correlation was 0.86905. The current capped market differs from the historical value-weighted market, with a Training correlation of 0.97661. Use the current vintage throughout the extension.
2. Hold the weight on each **shared restriction** constant across the two fitting problems. With N test assets, fit the unconditional model using (sum of N squared mean errors)/N. Fit the conditional model using (sum of the same N squared mean errors + sum of N volatility-managed squared mean errors)/N. This replaces d by N in both training normal equations of the original proposal. It prevents an automatic halving of the weight on every original restriction when the managed payoffs are introduced. Both models use precisely the same numerical penalty grid and unweighted ridge penalty. Validation uses the same average over all 2N test moments in every cell.
3. Weight each of the three equal 70-month inner blocks equally in the pooled squared-error curve. The square root of that curve supplies the RMSE input to both tuning rules. Final Validation has 60 months. A negative observed interaction favors the prespecified directional hypothesis. Report interval and size, along with each component contrast.
4. The parent empirical Bayes model observes a vector of estimated, volatility-scaled CAPM alphas y. In the two-layer specification its Gaussian prior covariance is Ω = τw²I + τc²CC′, where C indicates theme membership. With estimated sampling covariance V, zero prior mean, and invertible matrices, the posterior mean is Ω(Ω+V)⁻¹y. Multiplying out the precision-form posterior gives the same expression. JKP fit the variance components by marginal likelihood. The proposed SDF loss targets deferred pricing performance and estimates a different object. The native tangency application motivates the use of groups of tradable factors as SDF payoffs.
5. The four-model design, conditional volatility instrument, factor scaling, common endpoint, bootstrap and grid are project choices. The retained paper components are clustering and factor returns (JKP), conditional Euler moments (Chen, Pelger and Zhu, working manuscript sections I.A–B and II.A), and the local-window selector (Ciganovic, D'Amario and Tancioni, equations 3.9–3.12). The underlying moment norm is regularized GMM. RCF is pertinent to the source inference problem. Forward-only inner validation fits this project's intended timing.

The independent numerical check in `evidence/math_audit.json` verifies a conventional example with d=N=3. A production test must also verify the shared weight when the managed dictionary is appended. The derivation requires no new inference theorem.
